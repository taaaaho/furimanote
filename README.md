# furimanote

iOSアプリ「フリマ利益ノート」の公開情報（サポート・プライバシーポリシー・利用規約）を管理するリポジトリです。GitHub Pages（`main` ブランチの `/docs`）で公開しています。

- サポート: https://taaaaho.github.io/furimanote/
- プライバシーポリシー: https://taaaaho.github.io/furimanote/privacy.html
- 利用規約: https://taaaaho.github.io/furimanote/terms.html

ページの文言は `scripts/build_pages.py` で管理しています。編集後に `python3 scripts/build_pages.py` を実行してください。

ソースコードは非公開リポジトリ（`furimanote-code`）で管理しています。
